# 旅妆地图

一个面向景区旅拍用户的妆造案例与预约原型。用户可以从真实旅拍案例出发，查看妆造方、摄影方、参考价格与景点信息，并形成自己的出片计划。

## 当前功能

- 西安景区旅拍案例瀑布流
- 城市、景点与妆造风格探索
- 案例详情与原帖跳转
- 妆造方和摄影方信息整理
- 标准化预约流程演示
- 收藏、对比与出片计划
- 移动端图片浏览与交互动效

## 本地运行

需要 Node.js 22.13 或更高版本：

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run build:pages
```

GitHub Pages 的首次配置与发布说明见 [GITHUB_PAGES.md](./GITHUB_PAGES.md)。

## 说明

本项目目前是产品原型。案例中的价格、地址和商家接入状态仅在有明确来源时展示；标记为“需沟通”或“演示预约”的内容不代表真实商家已确认或已接入。
